# SPA без бэкенда: хранение в localStorage

Проект по требованиям — SPA без серверной части: записи гостей живут в
браузере (`localStorage`), маршрутизация — `react-router-dom` на клиенте.
Реальной альтернативы не было — выбор диктован требованиями проекта.

15-минутный квант сетки сюда не входит: он легко обратим и изолирован в
генерации слотов (`src/lib/bookings.ts`).

## Consequences

Локально запускается только фронтенд (`make dev`, http://localhost:5173);
бэкенда не существует и не планируется.
